# Contributing

Thank you for helping improve FINOLABS open source projects. This file applies to every public FINOLABS repository that does not publish its own `CONTRIBUTING.md`; a repository's own file takes precedence.

## Before opening a change

1. Open an issue for a material change in behavior, packaging, or scope.
2. Keep changes small and focused on one purpose.
3. Run the repository's own checks and say which ones you ran.
4. Never add credentials, tokens, private endpoints, captured prompts, or user data.
5. Use concise, imperative commit messages.

Changes reach the default branch through a pull request that passes the repository's checks. Maintainers review every pull request before it merges.

By participating, you agree to follow the [Code of Conduct](https://github.com/finolabs/.github/blob/main/CODE_OF_CONDUCT.md) and to license your contribution under the license the repository states.
